**NEXA MARKETING**
Landing page desenvolvida para uma agência fictícia de marketing digital, com foco em apresentar serviços, planos e conteúdos relacionados a estratégias de marketing.

📌 **SOBRE O PROJETO**

O Nexa Marketing é um projeto front-end desenvolvido como uma landing page institucional para uma agência de marketing.

O site foi criado com uma interface moderna e responsiva, apresentando informações sobre a empresa, serviços oferecidos, planos de contratação, depoimento de cliente e conteúdos relacionados a marketing digital.

O projeto utiliza HTML5, CSS3 e Bootstrap 5.3.3, além de Bootstrap Icons para alguns elementos visuais.

🎯 **OBJETIVO**

O objetivo do projeto é criar uma página profissional para apresentação de uma agência de marketing digital, facilitando a navegação do usuário e destacando os principais serviços e informações da empresa.

Entre os principais objetivos estão:

* Apresentar a empresa;
* Apresentar os serviços oferecidos;
* Exibir planos de contratação;
* Apresentar conteúdos relacionados a marketing;
* Facilitar a navegação entre as seções;
* Criar uma experiência responsiva para diferentes dispositivos.

🧩 **ESTRUTURA DA PÁGINA**

O site está dividido nas seguintes seções:

Navbar

Possui o logotipo da Nexa Marketing e links para navegação entre as principais áreas:

* Início;
* Serviços;
* Planos;
* Blog.

Também possui os botões “Entrar” e “Começar”.

Hero

É a seção principal da página e apresenta a mensagem:

“Ideias que transformam negócios.”

A seção também possui uma breve descrição da empresa, botões de ação e uma imagem de destaque.

Clientes

Apresenta nomes de empresas fictícias como forma de representar clientes ou parceiros da agência.

Serviços

Apresenta os principais serviços da Nexa Marketing:

* Estratégias personalizadas;
* Marketing que gera resultados.

Cada serviço possui uma descrição, botão de ação e imagem.

Depoimento

Apresenta um depoimento fictício de uma cliente sobre os serviços da agência.

Planos

Apresenta três opções de planos:

* Start;
* Business;
* Premium.

O plano Business possui um destaque visual como “Mais escolhido”.

CTA

Possui uma chamada para ação convidando o usuário a entrar em contato com a agência.

Blog

Apresenta conteúdos relacionados a:

* Estratégia;
* Marketing Digital;
* Inovação.

Footer

Contém informações da empresa, links para serviços e empresa e um campo para inscrição de e-mail.

📱 **RESPONSIVIDADE**

O projeto foi desenvolvido para funcionar em diferentes tamanhos de tela.

Foram utilizadas classes responsivas do Bootstrap, como:

container
row
col-lg-6
col-md-4
navbar-expand-lg

Também foram utilizadas regras @media no arquivo style.css para adaptar elementos em telas menores.

🎨 **IDENTIDADE VISUAL**
A identidade visual do projeto utiliza principalmente a cor laranja como cor de destaque.

A cor é aplicada em:

* Logo;
* Botões;
* Títulos de destaque;
* Ícones;
* Cards;
* Elementos de navegação.

A proposta visual busca transmitir criatividade, comunicação e dinamismo, características relacionadas ao segmento de marketing.

🚀 **COMO EXECUTAR O PROJETO**

Para executar o projeto localmente:

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo index.html.
4. Execute o arquivo utilizando um navegador ou uma extensão como Live Server.

Não é necessário instalar dependências adicionais para visualizar a página, pois o Bootstrap e o Bootstrap Icons são carregados através de CDN.
